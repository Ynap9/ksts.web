Máy của bạn chưa cài plugin ký số, hoặc plugin đang không chạy.
Bộ cài là một file KstsPlugin.exe duy nhất. Tải về rồi bấm đúp vào nó: nó tự cài trình đọc token bit4id nếu máy chưa có, rồi cài plugin và chạy nền. Xong quay lại màn hình này và bấm Kiểm tra lại.
Trình duyệt có thể cảnh báo file lạ khi tải — chọn Giữ lại để tiếp tục. Bước cài trình đọc token sẽ hỏi quyền quản trị. @if (boCai().exists === false) { Máy chủ chưa có bộ cài plugin. Vui lòng liên hệ quản trị hệ thống. }
